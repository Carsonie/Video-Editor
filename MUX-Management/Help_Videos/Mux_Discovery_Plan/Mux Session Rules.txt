
Rules for the Roles.

Visitor

1) Only sees the Login page and cannot click to other pages.

2) After login, user gets routed to the Knot page. Here the use can view the video.

3) This user has no access to the Reports or Home pages.

4) This user can return to the login page and log out of their session.


BCP-Admin

1) Again this user only sees the Login page and cannot click to other pages.

2) After login, this user gets routed to the Home page. 

3) This user has access to all functionality on the site.

4) This user can return to the login page and log out of their session.
