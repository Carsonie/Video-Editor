YouTube Data API: Service Account vs OAuth
Service Account:

Authentication happens server-to-server (your Node/Golang backend authenticates with YouTube)
No user login required
Credentials stored securely on your server
Best for your use case: fetching public videos from your own channel
Simpler implementation

OAuth:

Requires user to authorize your app to access their YouTube account
Token-based, user-specific
Useful if users needed to authenticate with their own YouTube accounts
Not needed for your scenario

For your setup: Use Service Account (simpler, since you're just pulling from your own channel)

Implementation Roadmap
1. YouTube Data API Setup (One-time)

Create a Google Cloud Project
Enable YouTube Data API v3
Create a Service Account & generate JSON credentials
Store credentials securely in your backend environment

2. Backend (Node/Golang)

Fetch videos dynamically from YouTube API using your channel ID

3. Database (MongoDB/SQL)

     }

5. Access Control
